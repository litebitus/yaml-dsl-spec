# yaml-dsl-spec-diagnostic-renderer

A [yaml-dsl-spec](https://crates.io/crates/yaml-dsl-spec) diagnostic written as a compiler writes an error, for a terminal or a log, from [yaml-dsl-spec](https://github.com/litebitus/yaml-dsl-spec).

Its API and rendering are designed in the [package design](https://github.com/litebitus/yaml-dsl-spec/blob/main/docs/package-design.md).
