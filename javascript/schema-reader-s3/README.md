# yaml-dsl-spec-schema-reader-s3

The YAML DSL standard's reader of schema URLs on S3, from [yaml-dsl-spec](https://github.com/litebitus/yaml-dsl-spec), registered on a schema cache to read `s3://<bucket>/<key>`.

Its API is designed in the [package design](https://github.com/litebitus/yaml-dsl-spec/blob/main/docs/package-design.md).
