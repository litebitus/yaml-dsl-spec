# Examples

Each folder is one DSL: its definition in `yaml-dsl.yml`, its document schema, and documents written in it. Open a folder in the [YAML DSL editor](https://github.com/litebitus/vscode-yaml-dsl-editor) to see the DSL read as the specification says.

| Example | Shows |
|---|---|
| [`layers/`](layers) | a common layer and its overlays, references, locals and placeholders |
| [`macros/`](macros) | a function table, function calls, and `loop` and `merge` macros |
| [`tags/`](tags) | YAML tags that stand for keys, and references written with them |
