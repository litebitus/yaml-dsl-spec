# yaml-dsl-spec-schema-reader-github

The YAML DSL standard's reader of schema URLs on GitHub, from [yaml-dsl-spec](https://github.com/litebitus/yaml-dsl-spec), registered on a schema cache to read `https://github.com/` links, a private release asset through GitHub's API with the machine's tokens.

Its API is designed in the [package design](https://github.com/litebitus/yaml-dsl-spec/blob/main/docs/package-design.md).
